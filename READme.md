# Mood Tracker AI

A Python application that allows users to record their daily moods and notes, then analyze mood patterns over time.

## Features

- Record daily mood
- Save mood entries with notes
- View all previous entries
- Analyze mood distribution
- Generate simple insights

## Technologies Used

- Python
- Datetime
- File Handling

## Future Improvements

- Mood visualization with Matplotlib
- Sentiment analysis using NLP
- Streamlit web interface
- AI-powered mood prediction

## Getting Started

```bash
python main.py
```
